HTML & CSS

Моя шпаргалка по веб-разработке

Всё самое важное в одном месте

1. Структура HTML-документа

Это базовый каркас (скелет) любой веб-страницы. Без него браузер не поймет, как отображать сайт.

<!DOCTYPE html>

<html>

<head>

<title>Название сайта</title>

</head>

<body>

Содержимое сайта

</body>

</html>

2. Основные HTML-теги

Это "кирпичи", из которых строится страница. Каждый тег отвечает за свой элемент.

<h1> — <h6>

Заголовки разных размеров (от самого большого до мелкого)

<p>

Абзац текста (обычный текст)

<a>

Ссылка на другой сайт или страницу

<img>

Изображение (картинка)

<table>

Таблица для вывода данных

<tr>

Строка внутри таблицы

<td>

Ячейка внутри строки таблицы

<header>

Шапка сайта (верхняя часть, где логотип и меню)

<main>

Основная часть контента страницы

<footer>

Подвал сайта (нижняя часть, где копирайт)

<center>

Выравнивание текста или элементов по центру

<hr>

Горизонтальная линия-разделитель

3. HTML-атрибуты

Это дополнительные настройки тегов, которые задают им поведение или внешний вид.

href

Указывает адрес ссылки (куда ведем)

src

Путь к файлу изображения

width

Ширина элемента (в пикселях или процентах)

height

Высота элемента

style

CSS-стили, записанные прямо внутри тега

rel

Тип связи с подключаемым файлом

border

Толщина рамки (границы) таблицы

align

Выравнивание элемента по горизонтали

4. Как подключить CSS?

Чтобы стили заработали, их нужно подключить в "голове" (head) HTML-документа.

<link rel="stylesheet" href="style.css">

5. Основы CSS

CSS — это язык, который отвечает за дизайн. Правило CSS состоит из трех частей: селектора (кого красим), свойства (что меняем) и значения (на что меняем).

p {

color: purple;

font-size: 20px;

}

p — селектор (выбирает тег абзаца)

color — свойство (меняет цвет текста)

purple — значение (делает его фиолетовым)

6. Основные CSS-свойства

Самые часто используемые команды для изменения внешнего вида.

color

Цвет текста

font-size

Размер шрифта

background-color

Цвет фона элемента

text-align

Выравнивание текста (влево, вправо, по центру)

border

Рамка вокруг элемента

margin

Отступ снаружи элемента

padding

Отступ внутри элемента

7. Отступы в CSS

Это важнейшая тема для верстки, чтобы элементы не слипались в кучу.

Margin — это расстояние снаружи (как отступить от соседнего дома).

Padding — это расстояние внутри (как расставить мебель внутри дома).

p {

margin: 20px;

padding: 10px;

}

8. Пример оформления текста

Пример того, как можно стилизовать заголовок с помощью CSS.

h1 {

color: purple;

font-size: 30px;

text-align: center;

}

9. Контекстные селекторы

Это селекторы, которые ищут элементы не просто по тегу, а по их вложенности (контексту). Например, "примени стиль только к тем тегам p, которые находятся внутри div".

Пишутся через пробел. Например: main p — значит взять все абзацы внутри main.

main p {

color: red;

}

Правило: Если между тегами стоит пробел, стиль применится ко всем вложенным элементам на любом уровне глубины. Если элементы нужно выбрать строго "родитель > ребенок", то используют знак больше: main > p.
